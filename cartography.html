🔄 Séquence d'actions

Création d'un modèle
1Navigation vers /models/create
2Saisie du nom
3Clic sur "Ajouter"
4Frontend appelle invoke('create_model', { name, fields })
5Backend génère UUID via uuid::Uuid::new_v4() 🆕
6Backend exécute INSERT INTO models ... RETURNING *
7Retour du modèle créé
Création d'un asset nouveau
1Navigation vers /assets/create
2Chargement des modèles via get_models
3Affichage formulaire (nom + select modèle)
4Saisie nom + sélection modèle
5Clic sur "Ajouter"
6Frontend appelle invoke('create_asset', { name, modelId, fields })
7Backend génère UUID
8Backend exécute INSERT INTO assets ... RETURNING *
9Retour de l'asset créé
Chargement de la page d'accueil
1Navigation vers /
2Layout SvelteKit (SSR=false)
3+page.ts appelle get_models
4Affichage liste des modèles
